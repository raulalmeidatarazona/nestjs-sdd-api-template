# Start an SDD slice

Read `AGENTS.md`, then `docs/INDEX.md`. Feature request: `$ARGUMENTS`.

Create or update the relevant `specs/features/<id>/spec.md` with observable acceptance criteria and failure behavior. Present the smallest first slice and its test plan. After the intent is settled, implement that slice, update `plan.md` and `validation.md`, run `make check`, and report exact evidence and remaining risks.
